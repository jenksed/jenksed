## Featured projects

### [Clusterwise](https://github.com/jenksed/clusterwise)

**Status: Active learning project**

An open-source, lab-driven Kubernetes apprenticeship and static learning system. It contains fifteen canonical capability sequences, original curriculum structure, diagrams, labs, validation tooling, and documentation published through a dependency-free static approach.

This demonstrates Kubernetes operational reasoning, systems decomposition, technical writing, information architecture, static-site engineering, and safety-conscious quality controls. The project deliberately separates published content, technical review, executed labs, learner testing, and stability, so published material should not be read as proof that every lab has been executed or learner-tested.

### [RoleForge](https://github.com/jenksed/roleforge)

**Status: In progress**

A local-first native macOS application for organizing career personas, applications, evidence, and grounded job-search workflows. It is implemented in Swift and SwiftUI and includes a working application foundation with persistence, résumé ingestion, drafting workflows, templates, attachments, and job-import work.

This demonstrates native application development, local-first product design, persistence and recovery thinking, requirement-driven planning, and QA-oriented release gates. Workflow completeness, provider hardening, manual QA, and release validation are still unfinished; it is not presented as a launched or production-ready product.

### [oc-elixir-scout](https://github.com/jenksed/oc-elixir-scout)

**Status: Early developer-tooling project**

A lightweight, read-only impact scout for AI coding agents working in Elixir repositories. Its primary implementation is Bash. It gathers pre-edit context such as likely callers, related tests, nearby references, risk hints, and suggested validation commands, and can work without an installed Elixir runtime while optionally using tools such as `mix`, `git`, and `rg`.

This demonstrates developer tooling, Elixir and OTP learning, shell scripting, graceful degradation, and safe-change thinking. Its analysis is heuristic and substring-based rather than full AST analysis, and the repository documents those limitations.

### [supportlab-relay](https://github.com/jenksed/supportlab-relay)

**Status: Prototype**

An early Go prototype for connecting learner-local terminal sessions to browser-based SupportLab experiences. It includes a local WebSocket server, pairing-message groundwork, PTY input and output streaming, terminal resizing and signals, and an initial validation command. It binds to localhost by default and guards routable binding.

This demonstrates Go development, WebSocket and PTY experimentation, local-first system boundaries, protocol design, and security-default thinking. Parts of the pairing lifecycle and rate limiting remain unfinished, so it is not described as secure for untrusted networks or as a completed remote-terminal platform.

### [macadmin](https://github.com/jenksed/macadmin)

**Status: Public utility collection**

A collection of Zsh-based utilities for inspecting and managing macOS systems through a shared command dispatcher. Commands cover system information, updates, cleanup, settings, networking, backups, and basic hardening.

This demonstrates practical support automation, shell scripting, command-line interface design, structured logging, and operational safety. The utilities include dry-run behavior, confirmation gates, protected operations, read-only probes, and lightweight tests with mocks. It is not an enterprise device-management system, an MDM replacement, or a fully audited security tool.
